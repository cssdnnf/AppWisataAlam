# Kredit aset visual

Aplikasi ini memakai foto berlisensi Creative Commons dari Wikimedia Commons
dan font Plus Jakarta Sans. Nama foto di bawah mengacu pada file di
`app/src/main/res/drawable-nodpi/`.
